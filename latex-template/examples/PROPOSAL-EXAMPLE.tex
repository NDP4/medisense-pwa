\section{Ringkasan Kebutuhan}
Warung Sembako Budi membutuhkan aplikasi Point of Sale (POS) untuk mencatat
transaksi penjualan, mengelola stok barang, dan menghasilkan laporan
penjualan harian. Aplikasi dipakai oleh 3 kasir secara bergantian dan harus
tetap berfungsi saat koneksi internet terputus.

\section{Lingkup Kerja}
\subsection*{Termasuk dalam lingkup}
\begin{itemize}[leftmargin=1.4em]
  \item Modul transaksi kasir (offline-first)
  \item Manajemen stok barang
  \item Laporan penjualan harian
  \item Manajemen akun untuk 3 kasir dengan role berbeda
\end{itemize}

\subsection*{Tidak termasuk dalam lingkup ini}
\begin{itemize}[leftmargin=1.4em]
  \item Integrasi pembayaran digital (dapat diusulkan terpisah)
  \item Aplikasi mobile companion
\end{itemize}
